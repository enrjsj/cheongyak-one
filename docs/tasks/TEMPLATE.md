| 항목 | 명령 또는 확인 방법 | 결과/증거 |
| --- | --- | --- |
| 재현 또는 변경 전 기준 | | |
| 개발 중 관련 검사 | 변경한 단위 파일 / 브라우저 시나리오 / 백엔드 클래스 | |
