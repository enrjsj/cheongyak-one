## 구현과 검증

- 실행 모드: auto → 총괄 구현 + 독립 읽기 리뷰. AGENTS의 분업 지침에 따라 계산 계약·상태 회귀 검토를 `/root/cash_plan_review`에 위임. 공유 소스 읽기만, 에이전트 쓰기/테스트/재위임 금지. 총괄이 모든 코드·기록과 테스트 포트 4173/4180/8081을 소유한다.
- 계산식의 중도금 대출 이중 계산 결함은 발견되지 않았다. 실제 확인한 문제는 쉼표 금액 거부, 필수 입력 위치 안내 부족, 주택형 선택 전 빈 폼, 상세에도 적용된 520px 폭이다.
- 첫 주택형 금액만 자동 반영. 비율·대출·비용은 빈칸 유지, 사용자가 명시적으로 없음을 선택할 수 있다. 현재 결과와 고정 비교 snapshot의 독립성·로컬 파일 저장/비전송 계약 유지.
- React 스킬 검토: 훅은 조건부 return 전, 단순 파생값은 render 계산, 별도 캐시/의존성/패키지 추가 없음. 오류 상태 객체로 같은 오류 재제출도 초점 이동, 공고 ID별 remount 유지.

## 인수인계

- 증거: `.harness/oct29-cash-ui/`에 단위·기존/신규 브라우저 로그와 이미지. 초기 실패는 최종 통과와 구분한다.
- 최종 고정본: `.harness/oct29-cash-ui/frozen-source.json` 442파일. 하네스 fingerprint `5972d12b536af551808d51bcf790800ff8a9fd9ca5df2055131454ae98466e24`. 이후 결과 문서만 추가하고 소스 동일성 및 docs 하네스를 별도로 확인한다.
- 표준 Playwright Chromium/WebKit은 로컬 환경에 없고 시스템 Chromium만 사용 가능하다. 전체 표준 브라우저·실제 iPhone·실제 인증·PostgreSQL은 최종 원격 CI 확인 전 미검증이다. 실제 기기 노치/소프트키보드·실제 보조기기는 CI 에뮬레이션과 별도다.
- 원격 반영: 기존 사용자 커밋·푸시·배포 지시에 따라 최종 PR head의 기존 CI를 확인한 뒤 GitHub main 자동 배포를 사용한다. 원격 결과는 PR 본문·로컬 증거에 남기며 기록만을 위한 재배포는 하지 않는다.
