# 주택형 부분 정보와 상세 재시도 안내

- 기준: main `f7565d62d8098cd8abec7831878759b11640b17e` (PR #136). 시작 시 작업 사본 변경 없음, 원격 fetch 후 동일 내용 확인.
- 목표: 분양 주택형의 일부 미제공/잘못된 수치를 공고 확인 목록에 표시하고, 정상·오류·재시도·공고 전환 경계를 검증한다.
- 제외: API 계약, 원본 데이터, 인증, DB, CI/클라우드 설정, 실제 AI/알림/운영 쓰기.
- 완료 기준: 0원/0세대 및 양수 소수 면적을 보존한다. 누락과 오류를 구별해 전체 주택형 기준 필드별 건수를 표시한다. 임대에 분양 경고를 적용하거나 수집 실패를 추론하지 않는다.

## 구현과 분업

- 총괄 단일 쓰기, 구현 후 기본 서브에이전트 읽기 전용 리뷰. 역할 TOML 자동 로딩을 가정하지 않고 reviewer 지침을 전달한다. 재귀 위임·리뷰어 테스트/쓰기 없음.
- `unitTypeTools.ts`의 기존 unitValue 규칙을 재사용한다. 면적·가격·일반/특별/전체 공급 필드별로 누락과 오류를 집계해 최대 10개 항목으로 제한한다. 합계나 누락 수치를 역산하지 않는다.
- `NoticeQualityPanel.tsx`가 분양 공고에만 주택형 안내를 합친다. 현재 검색/정렬과 무관한 전체 상세 배열 기준이며 추가 API 요청·상태·저장소가 없다.
- 단위 회귀 4개와 Chromium/iPhone 공통 브라우저 회귀 2개. 부분 자료 표시, 320px 넘침, 이전 경고 후 재조회 실패, 재시도 대기·정상 복구, 임대 전환을 검사한다.
- 총괄이 문서·통합·포트 4173 테스트를 소유하며 검증은 직렬 실행한다.
