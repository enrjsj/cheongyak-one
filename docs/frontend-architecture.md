# 프런트 화면 책임과 변경 안내

React/Vite 단일 페이지 앱이다. API 계약은 `frontend/src/api.ts`가 관리하고, 쿠키·CSRF·요청 시간 제한은 공통 요청 함수에서 처리한다.

| 파일 | 책임 |
| --- | --- |
| `App.tsx` | 검색·회원·관심·비교 상태의 조합, URL/뒤로가기, 요청 취소, API 변경 호출 |
| `NoticeDetailDialog.tsx` | 상세 표시, 공급 표, 준비 상태 입력, 상세 모달 접근성. 데이터와 콜백은 상위 화면에서 받는다. |
| `noticePresentation.ts` | 공고·주택형 표시용 변환, 한국 날짜·금액·면적 표시. 네트워크·저장소 접근 없음 |
| `favoritePresentation.ts` | 관심청약 상태·결과·체크리스트 표시와 우선순위 |
| `Icon.tsx` | 공통 장식용 SVG 아이콘 |
| `CashPlanCalculator.tsx` / `cashPlan.ts` | 화면 한정 입력 상태 / 원 단위 검증·순수 계산 |
| `useDialogAccessibility.ts` | 모달 포커스 이동·복원, Tab 순환, Escape, 중첩 모달 스택 |
| `AiConsultationPanel.tsx` | 동의·상담 요청·근거 표시. 현금 계산기 입력을 참조하지 않는다. |

상세 요청 취소와 URL 처리는 App에 남긴다. 상세 창은 항상 같은 컴포넌트 위치에서 렌더링해 닫힘 시 포커스를 복원한다. 계산기는 공고 ID로 상태를 분리하고 상세 로딩·오류 중에는 표시하지 않는다. 다른 공고, 상세 닫기·재열기, 주택형 변경 시 계산 입력과 결과를 초기화한다. 단순 표시 변경에서 API/URL 상태를 별도로 복제하지 않는다.

## 현금 계획의 계산 계약

분양 주택형 선택 시 수집된 `maxPrice`(원)를 기준금액에 넣는다. 최고 공급금액은 실제 선택 동·호수 금액이 아니며 사용자가 수정할 수 있다. 유효한 금액이 없으면 빈 입력을 유지한다. 주택형 자료가 없거나 임대 공고이면 분양 계산을 적용하지 않는다.

모든 입력은 필수이며 공고 금액 외에는 기본 비율·대출·세금 값을 만들지 않는다. 없다고 확인한 대출·추가 비용만 0을 입력한다. 금액은 0~1조 원의 정수(공급금액은 양수), 비율은 0~100%의 소수 두 자리까지 지원한다. 비율 합은 100% 이하여야 한다.

- 공급금액 P, 계약금 D=floor(P×계약금 비율), 중도금 M=floor(P×중도금 비율), 잔금 B=P−D−M.
- 중도금 대출 Li는 M 이하. 중도금 자기자금은 M−Li.
- 잔금 시 총 대출 Lf는 B+Li 이하. 잔금 단계 자기자금은 B+Li−Lf+추가 비용.
- 총 자기자금은 P−Lf+추가 비용. 단계별 부족액은 max(0, 누적 자기자금−현재 현금).

원 단위 금액과 0.01% 단위를 정수로 변환하고 곱셈은 BigInt를 사용한다. 원 미만 차액은 잔금에 남긴다. 중도금 대출은 잔금 시 전액 상환하고, 추가 비용은 잔금 단계에 지출한다고 가정한다. 실제 회차별 납부일·이자율·세율·LTV·대출 승인·향후 소득은 추정하지 않는다. 이미 납부한 현금의 대출 환급 시나리오는 지원하지 않는다.

입력값을 바꾸면 기존 결과를 지운다. 값은 React 상태에만 존재하며 URL·localStorage·서버·AI에 저장/전송하지 않는다. 공유 링크는 공고만 공유한다.

## 검증과 배포

- `npm test --prefix frontend`: 타입·빌드와 순수 계산/공통 로직 테스트.
- `npm run test:e2e --prefix frontend`: Chromium 전체 흐름. 신규 계산은 금액·초기화·오류·모바일을 검증한다.
- CI의 iPhone WebKit: 상세 열기·복구·뒤로가기·포커스 등 공통 모달 회귀 검증.
- 기존 CI의 실제 회원 세션 테스트는 API 프록시·쿠키 흐름을 검증한다.
- 배포 후 `node scripts/verify-deployment.mjs <frontend HTTPS origin> <API HTTPS origin> <40자리 커밋>`으로 사이트/직접 API/프록시 버전 일치와 상태·인증 응답을 확인한다.

운영 계산은 브라우저에서만 수행하므로 DB 변경이나 AI 활성화가 필요 없다. 현재 금액 출처와 가정이 올바르게 표시되는지도 실제 공고 상세에서 확인한다.
